# Verve\-Relocate 磁盘目录迁移模块\-详细需求规格说明书（最终完整版｜含自定义目录\+彻底排除沙盒）

## 文档说明

- 项目归属：Verve 内置模块（Rust \+ GPUI）

- 运行平台：macOS 专属（Apple Silicon / Intel）

- 运行场景：本机内置SSD ⇋ 雷电/USB4 外置NVMe固态移动硬盘

- 交付对象：Coding Agent（可直接逐行落地编码）

- 当前版本最终修订：彻底屏蔽沙盒目录、支持全自动智能分组、支持用户自定义目录迁移、完整迁移\+断点续传\+可视化进度\+完整回滚体系

- 核心约束：不依赖 Time Machine 业务回滚、绝对路径Symlink、禁止递归删链、全程异步UI不阻塞、黑名单强拦截

## 1\. 整体功能目标

本模块为 macOS 专用磁盘空间释放工具，核心能力如下：

1. 全自动扫描用户目录，**动态智能聚类分组**，无硬编码固定任务，适配任意用户目录结构，傻瓜式一键批量选择；

2. 彻底屏蔽 macOS 沙盒容器目录，全程不扫描、不展示、不可选中、不可迁移；

3. 支持系统自动分组迁移 \+ **用户手动添加自定义目录迁移**双模式；

4. 安全迁移本机大体积缓存/工程目录至外置高速固态，原路径生成绝对路径符号链接，应用无感知；

5. 完整串行任务队列、断点续传、实时速度/进度可视化、日志记录；

6. 完整事务级回滚能力：一键撤销迁移、外链数据写回本机、清理符号链接；

7. 外置磁盘介质检测、空间预校验、文件占用检测、文件系统风险提示、冲突交互；

8. 全部任务持久化，重启不丢失、支持单任务回滚、分组批量回滚。

## 2\. 全局强制规则（不可修改）

### 2\.1 全局黑名单（强拦截）

所有黑名单目录：扫描直接跳过、不加入内存列表、不展示在UI、禁止任何迁移/选中/操作。

黑名单完整列表：

- 系统级：/System、/Library、/private、/dev、/Volumes、/\.Trash

- 用户沙盒强制排除：\~/Library/Containers、\~/Library/Group Containers

- 用户垃圾目录：\~/\.Trash

- 系统挂载与核心隐藏目录

### 2\.2 Symlink 强制规范

- 所有迁移任务**仅创建绝对路径符号链接**；

- 删除链接仅执行单删链接操作，**禁止任何递归删除目录操作**；

- 严格隔离：删链 ≠ 删文件，杜绝误删外置硬盘数据。

### 2\.3 Time Machine 边界

- 业务迁移、业务回滚**完全不依赖、不调用 Time Machine**；

- Time Machine 仅作为极端磁盘损坏/丢失的灾难兜底，不参与模块逻辑。

### 2\.4 异步UI规范

所有磁盘IO、进程检测、命令调用、文件复制、队列执行全部异步，严禁阻塞 GPUI 渲染线程。

## 5\. 扫描与自动聚类逻辑

1. 自动扫描 /Users/当前用户 全部目录；

2. 过滤全部黑名单目录；

3. 遍历有效目录，按优先级匹配规则，**一个目录仅归属一个分组**；

4. 自动剔除不存在目录、自动剔除空分组；

5. 汇总每组总占用大小；

6. 容量大于5GB的分组自动标记UI【推荐迁移】；

7. 未匹配规则目录归入【其他目录】，支持手动选择；

8. **沙盒容器目录全程无任何展示、无任何入口、不可操作**。

## 6\. 新增功能：用户自定义目录迁移（完整需求）

### 6\.1 功能说明

在自动智能分组之外，提供用户自由添加自定义目录的能力，用户可手动选择本机任意合法目录（黑名单除外）加入迁移队列，实现完全自定义迁移。

### 6\.2 UI入口

分组面板下方固定增加按钮：【\+ 添加自定义迁移目录】

弹窗支持：macOS 文件目录选择器，仅可选择文件夹，禁止选择文件。

### 6\.3 自定义目录校验规则（强制）

1. 用户选择目录后，首先执行**黑名单强校验**，命中黑名单直接弹窗拒绝：“该目录禁止迁移”；

2. 校验目录必须存在、必须为本地用户目录；

3. 禁止选择外置目录、系统根目录、挂载目录；

4. 自动计算自定义目录大小，加入总预估释放空间；

5. 自定义目录单独归类为【用户自定义目录】分组，UI独立展示；

6. 支持多条自定义目录叠加、支持单独勾选/取消；

7. 自定义目录同样完整支持：迁移、进度展示、持久化、一键回滚。

### 6\.4 自定义目录生命周期

- 添加后实时进入任务预览队列；

- 跟随批量任务一起串行执行迁移；

- 持久化写入 tasks\.jsonl，标记 group\_name = "用户自定义目录"；

- 支持单条自定义目录独立回滚。

## 7\. 外置磁盘预检测体系（迁移前强制执行）

用户选择外置目标根目录后自动执行全部检测，不通过禁止迁移。

### 7\.1 检测项

- 磁盘类型：必须为外置磁盘，拦截内置磁盘；

- 剩余空间：外置可用空间 ≥ 全部待迁移总容量，不足拦截；

- 介质识别：SSD / HDD；

- 文件系统识别：APFS / exFAT / 其他。

### 7\.2 弹窗提示逻辑

- 雷电/USB4 SSD：轻提示，允许直接迁移；

- 机械硬盘：强制警告弹窗，用户手动确认后方可继续；

- exFAT：弹窗提示权限风险，推荐 APFS。

## 8\. 批量迁移引擎（原子事务级）

### 8\.1 任务队列规则

所有自动分组目录 \+ 所有用户自定义目录，统一进入**串行队列**逐条执行，防止IO抢占、避免文件损坏。

### 8\.2 单目录迁移标准流程（不可省略）

1. **进程占用检测**：lsof 检测目录是否被IDE/模拟器/软件占用，占用则终止任务并提示关闭程序；

2. **目标冲突检测**：外置路径存在同名目录，弹窗三选项：合并 / 备份重命名 / 跳过；

3. **异步断点续传复制**：超大目录持续传输，中断重启可继续；

4. **可选SHA256完整性校验**；

5. 全部文件校验成功后，删除本机原始目录；

6. 原路径创建**绝对路径Symlink**指向外置目录；

7. 写入持久化任务，状态置为 Migrated。

## 9\. GPUI 可视化进度体系

- 全局总进度百分比；

- 当前任务目录名称、实时传输速度 MB/s、单文件进度；

- 实时滚动日志面板（Info/Warn/Error）；

- 队列控制：暂停、继续、跳过失败、重试失败项；

- 实时汇总预估释放空间、已释放空间。

## 10\. 完整回滚引擎（核心撤销能力）

### 10\.1 回滚前置条件

外置磁盘必须正常挂载，否则提示无法回滚，依赖 Time Machine 兜底。

### 10\.2 标准回滚流程

1. 读取持久化任务，校验外置目标目录有效性；

2. **安全删除本机 Symlink（仅删链接）**；

3. 外置目录完整断点续传复制回本机原始路径；

4. 复制完成弹窗二选一：保留外置副本 / 删除外置副本；

5. 任务状态更新为 RolledBack。

### 10\.3 回滚粒度

- 单条任务独立回滚；

- 整组批量回滚（自动分组/自定义分组均支持）。

### 10\.4 UI固定提示文案

一键回滚：将外置固态文件复制回内置磁盘，移除符号链接。⚠️ 本功能依赖迁移所用外置固态保持连接；硬盘丢失/损坏请依靠Time Machine历史备份兜底恢复。

## 11\. 非功能需求

- 全部IO异步、界面零阻塞；

- 所有覆盖、删除、替换操作必须弹窗确认；

- 任务文件向前兼容；

- 双层黑名单拦截：扫描层\+任务执行层双重校验，杜绝漏网迁移。
